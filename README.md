# 家族旅遊短劇：我幫你帶

四人演出、約 5 分的單一場景舞台劇，含角色設定、舞台配置、道具與完整台詞。網頁版請開 index.html，或啟用 GitHub Pages 後直接用瀏覽器看。

每次改動都升 index.html 頁首與頁尾的版本號，說明寫進 `changelog/版本紀錄.md`（最新的在最上面）。台詞本頁首會印出當下的版本號，所以要先升版號，再產台詞本。

## 改劇本

劇本的正本是 `劇本.md`，直接改這個檔，不要改 index.html 裡的劇本段落。格式：

- `## 場景一　拍照與微小不快 1:00–1:45`：段落標題，最後是時間。
- `爸爸：（微怒）壓都壓爛了還擠！`：一句台詞一行，角色名（阿嬤、爸爸、媽媽、小瑜）加全形冒號。全形括號裡是動作，台詞本不會畫底線。
- `（燈暗。）`：整行用全形括號包起來，是舞台指示。
- `> 走位：…`、`> 演法：…`：走位與演法提示。演法只在網頁上，不印進台詞本。
- `> 情緒：` 下一行起寫 `> - 阿嬤：…`，一個角色一行：這段的情緒建議。台詞本上只列自己那一行。

改完後依序執行：

```sh
python3 tools/script_md.py build
python3 tools/make_sides.py
```

第一行把 `劇本.md` 寫回 index.html 的劇本段落，並更新下載區的台詞句數。第二行重新產生 `sides/` 裡四個角色的台詞本 PDF，需要 Google Chrome；劇名和片長從 index.html 的標題與副標讀。

## 台詞本

每個角色的台詞本 PDF 在 sides/ 資料夾，自己的台詞加粗並畫底線，開口前對方的最後一句用粗斜體當接話提示，可直接列印：阿嬤 amah.pdf、爸爸 aming.pdf、媽媽 shufen.pdf、小瑜 xiaoyu.pdf（檔名沿用 v3，下載連結才不會變）。
